# Changelog

All notable changes to this project are documented here.

## 0.0.2 - 2026-08-17

- Upgrade `@xmldom/xmldom` to 0.9.11 for the upstream XML name-validation and parser ReDoS security fixes.
- Keep the standalone runtime and File Viewer adapter on the same exact 0.0.2 release line.

## 0.0.1 - 2026-08-17

- Initial standalone `iwork-viewer` package for Apple Pages, Numbers, and Keynote.
- Initial `@file-viewer/renderer-iwork` adapter package.
- iWork '09 XML/APXL and modern Snappy/IWA parsing in a bounded module Worker.
- Structural, browser, cold-install, and fixed-font visual regression evidence.
